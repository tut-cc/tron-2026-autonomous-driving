# 実機確認の手順

書き込み方法は [DEVELOPMENT.md](DEVELOPMENT.md)、配線は [README.md](../README.md) と [PIN_OWNERSHIP.md](PIN_OWNERSHIP.md) を参照してください。

## 安全の原則

- 確認は2段階に分ける。**段階 A（モーター用電池ボックスのスイッチOFF）**：モーター系に給電せず、状態遷移と出力信号だけを見る。**段階 B（同スイッチON）**：段階 A がすべて合格した後だけ、車輪を浮かせて短時間回す。モーターやDRV8833のはんだ付け済み配線を取り外す必要はない。
- 段階 B では手元に物理キル（電池ボックスのスイッチを即座にOFFにできる状態）を用意し、周囲に人を近づけない。スイッチOFFで実際にモーター系の給電が遮断されることを先に確認する。
- 床上走行は段階 B の合格後、必要最小限だけ。速度・停止距離は測っていないので保証値として説明しない。
- **人を車両の前に立たせて AI の停止を試さない**（印刷した写真や模型を使う）。

写真の車体では、後方から前方を見てスイッチを左に倒すと、モーター用電源がONになります。取り付け向きや配線を変えた場合は、テスターでON/OFFを確認してください。

実車の距離センサはM5Stack Unit ToF4M（U172）です。確認前に[READMEの接続表](../README.md#接続)と照らし、赤＝5V（J18-5）、黒＝GND（J24-7）、黄＝SDA（J24-9）、白＝SCL（J24-10）の配線を確認してください。端子が異なる場合は通電せず、原因を調べてください。

## 段階 A：モーター用電池ボックスのスイッチOFF

モーター用電池ボックスのスイッチをOFFにし、車輪を浮かせて書き込む。P006/P402/P412/P413 にロジックアナライザ等をつなぐと出力も確認できる。

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 起動して Web（http://192.168.2.200/）を開く | 状態と前方距離が表示される。起動直後は MANUAL・停止 |
| 2 | MANUAL で左手の ▲ を押す・離す、右手の ◀ ▶ を押す、両方を同時に押す | Webの操作と停止状態を確認する。タイヤは回らない。GPIO出力の有無と左右はロジックアナライザ等を接続した場合だけ判定する |
| 3 | 白い路面の外で AUTO を押す | 「走行路を認識できていません」で拒否（`g_vc_start_result`=4） |
| 4 | 白い路面の上で AUTO を押す | AUTOになる。タイヤは回らない。GPIO出力は測定器を接続した場合だけ確認する |
| 5 | AUTO 中に白い路面から外す（またはカメラを覆う） | TOR：出力 0、3 秒のカウントダウン |
| 6 | TOR 中に「手動操作に切り替える」 | MANUAL（停止）に戻る。路面に戻しても自動で AUTO にならない |
| 7 | もう一度 TOR にして 3 秒待つ | 「引継ぎ時間切れ」で停止。WebのRESET後も自動再発進せず、再操作が必要。RESETが効かない場合はモーター用スイッチをOFFにして基板を調べる |
| 8 | モーター用スイッチOFFのまま、AUTOの走行状態で箱を前方100 mmに置く。箱を離して再びAUTOを開始し、別試行で50 mmに置く | 100 mm以内で停止（`DISTANCE_PRESTOP`、開始も拒否）。50 mm以内では緊急停止（`DISTANCE_EMERGENCY`）。箱を離しても自動では再発進しない。手をセンサ前に出さない |
| 9 | 人・車の写真をカメラの前にかざす | 映像に紫枠、Webに手動切替の推奨とログ。検知だけではAUTOのモード・モーター出力は変わらない。障害物が走行路を隠すと、別の走行路判定でTORになる場合がある。ToF停止は独立して有効 |
| 10 | WebのSTOPとRESET | STOPで停止し、操作中断画面のRESETで再操作可能な状態に戻す。WebのRESETだけではM33のESTOPは解除されない。ESTOP入力が発生した場合はモーター用スイッチをOFFにし、原因を確認してから基板リセットが必要 |
| 11 | MANUAL 走行中に Web を閉じる・Wi-Fi を切る | 300 ms で停止 |
| 12 | 各停止のあと | `g_control_fault` が 0（内部故障なし） |

AI が動いているかは、Web の映像（`/video_feed`、240×180 の BMP。水色＝コース境界、黄＝生成走行路、紫枠＝人・車の検出）、デバッガ変数（`g_ai_detector_status_code`=100、`g_ai_person_count` など、`DEVELOPMENT.md` 参照）または USB の PC ビューアの `AI_DETECTION,...` 行で確認する。映像は制御より低優先のベストエフォートで、INFO に GET 時間・新規フレーム率・更新停止を表示する。映像の更新速度から AI の鮮度や安全性を判断しない。

## 段階 B：モーター用電池ボックスのスイッチON（段階 A が全合格した後だけ）

1. 車輪を完全に浮かせ、物理キルを用意する。電流制限できる電源があれば低い電流上限から始める。
2. MANUAL で短く前進し、左右が前向きに回ることを確認する。「左」で右タイヤだけ、「右」で左タイヤだけが前に回ること。逆回転なら `MOTOR_LEFT_INVERTED` / `MOTOR_RIGHT_INVERTED`、回るタイヤが左右逆なら `MOTOR_SWAP_SIDES`（いずれも `control/include/motor_build_profile.h`）を直して両コアをクリーンビルドする。
3. AUTO で走行路の左寄り・右寄りに置き、路面の中央へ戻る向きに曲がることを確認する（カメラは 180° 回転して取り付けているため、MANUAL と別に確認する）。
4. 左右旋回、STOP、ToF 100 mm 停止・50 mm 緊急停止、AUTO と TOR を短時間ずつ確認する。ToFの2つの距離はそれぞれ走行状態から別々に試す。WebにESTOPボタンはない。50 mm は衝突回避を保証する距離ではない（VL53L1X の保証最短測距は 40 mm。速度・センサー位置・制御遅延・惰走を含めて余裕を評価する）。
5. 異音・発熱・過電流・意図しない再始動があれば即中止。

## 中止と終了

異臭・発熱・煙・異常電流・配線の緩み・想定外の出力のどれかがあれば、電池ボックスのスイッチをOFF → 必要ならモーター電池を取り外す → 基板の電源を切る、の順で止める。終了時も同じ順。車輪が接地したまま電源を入れ直さない。
