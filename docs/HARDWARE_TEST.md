# 実機確認の手順

書き込み方法は `DEVELOPMENT.md`、配線は `README.md` と `PIN_OWNERSHIP.md` を参照してください。

## 安全の原則

- 確認は2段階に分ける。**段階 A（VM OFF）**：モーター電源を物理的に外し、状態遷移と出力信号だけを見る。**段階 B（VM ON）**：段階 A がすべて合格した後だけ、車輪を浮かせて短時間回す。
- 段階 B では手元に物理キル（電池を即座に外せる状態）を用意し、周囲に人を近づけない。
- 床上走行は段階 B の合格後、必要最小限だけ。速度・停止距離は測っていないので保証値として説明しない。
- **人を車両の前に立たせて AI の停止を試さない**（印刷した写真や模型を使う）。

## 段階 A：VM OFF

モーター電池を外し、車輪を浮かせて書き込む。P006/P402/P412/P413 にロジックアナライザ等をつなぐと出力も確認できる。

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 起動して Web（http://192.168.2.200/）を開く | 状態と前方距離が表示される。起動直後は MANUAL・停止 |
| 2 | MANUAL で左手の ▲ を押す・離す、右手の ◀ ▶ を押す、両方を同時に押す | 押している間だけ出力、離すと停止。◀ で右タイヤだけ、▶ で左タイヤだけ前に回る。▲＋◀/▶ で曲がりながら前進。後退はない |
| 3 | 白い路面の外で AUTO を押す | 「走行路を認識できていません」で拒否（`g_vc_start_result`=4） |
| 4 | 白い路面の上で AUTO を押す | AUTO になり出力が出る |
| 5 | AUTO 中に白い路面から外す（またはカメラを覆う） | TOR：出力 0、3 秒のカウントダウン |
| 6 | TOR 中に「手動操作に切り替える」 | MANUAL（停止）に戻る。路面に戻しても自動で AUTO にならない |
| 7 | もう一度 TOR にして 3 秒待つ | 「引継ぎ時間切れ」で停止。`ABORT` で解除 |
| 8 | 定規で手や箱を前方 100 mm、次に 50 mm に置く | 100 mm 以内で停止（`DISTANCE_PRESTOP`、開始も拒否）、50 mm 以内で緊急停止（`DISTANCE_EMERGENCY`）。101 mm 以上に離すと解除されるが自動では再発進しない |
| 9 | 人・車の写真をカメラの前にかざす | 映像に紫枠。進路上なら緊急停止（停止理由 `AI_OBSTACLE`）。取り除いても自動では再発進しない |
| 10 | `ABORT` / `ESTOP` | 即時停止。`ESTOP`（`BUTTON_EMERGENCY`）は `RESET` やセンサー回復では解除されず、基板リセットで解除 |
| 11 | MANUAL 走行中に Web を閉じる・Wi-Fi を切る | 300 ms で停止 |
| 12 | 各停止のあと | `g_control_fault` が 0（内部故障なし） |

AI が動いているかは、Web の映像（`/video_feed`、240×180 の BMP。水色＝コース境界、黄＝生成走行路、紫枠＝人・車の検出）、デバッガ変数（`g_ai_detector_status_code`=100、`g_ai_person_count` など、`DEVELOPMENT.md` 参照）または USB の PC ビューアの `AI_DETECTION,...` 行で確認する。映像は制御より低優先のベストエフォートで、INFO に GET 時間・新規フレーム率・更新停止を表示する。映像の更新速度から AI の鮮度や安全性を判断しない。

## 段階 B：VM ON（段階 A が全合格した後だけ）

1. 車輪を完全に浮かせ、物理キルを用意する。電流制限できる電源があれば低い電流上限から始める。
2. MANUAL で短く前進し、左右が前向きに回ることを確認する。「左」で右タイヤだけ、「右」で左タイヤだけが前に回ること。逆回転なら `MOTOR_LEFT_INVERTED` / `MOTOR_RIGHT_INVERTED`、回るタイヤが左右逆なら `MOTOR_SWAP_SIDES`（いずれも `control/include/motor_build_profile.h`）を直して両コアをクリーンビルドする。
3. AUTO で走行路の左寄り・右寄りに置き、路面の中央へ戻る向きに曲がることを確認する（カメラは 180° 回転して取り付けているため、MANUAL と別に確認する）。
4. 左右旋回、STOP/ESTOP、ToF 100 mm 停止・50 mm 緊急停止、AUTO と TOR を短時間ずつ確認する。50 mm は衝突回避を保証する距離ではない（VL53L1X の保証最短測距は 40 mm。速度・センサー位置・制御遅延・惰走を含めて余裕を評価する）。
5. 異音・発熱・過電流・意図しない再始動があれば即中止。

## 中止と終了

異臭・発熱・煙・異常電流・配線の緩み・想定外の出力のどれかがあれば、物理キル → モーター電池を外す → 基板の電源を切る、の順で止める。終了時も同じ順。車輪が接地したまま電源を入れ直さない。
